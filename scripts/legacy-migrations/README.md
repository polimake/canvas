# Migraciones históricas de Studio

Estos scripts pertenecen a la retirada del editor anterior. Algunos contienen
rutas de scratchpads, identificadores y estructuras de datos de aquella operación.
No son comandos generales de importación ni se ejecutan en build o instalación.

Para leer documentos nuevos, usa `@pm/canvas/parsers`; para convertir el formato
legacy, usa `legacyToScene` desde `@pm/canvas/converters`.

Antes de reutilizar un script, revisar todas sus entradas, rutas y efectos. Su
presencia aquí conserva el historial, no garantiza que siga siendo aplicable.
